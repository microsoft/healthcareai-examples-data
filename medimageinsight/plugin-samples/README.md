# MedImageInsight plugin samples

Chest X-ray images used as sample inputs for the MedImageInsight Copilot plugin
(walkthrough and smoke test).

## Provenance

**Source:** NIH ChestX-ray14 dataset
**Provider:** NIH Clinical Center
**Access:** <https://nihcc.app.box.com/v/ChestXray-NIHCC>

| File | Patient / Study |
|------|-----------------|
| `00026132_011.png` | Patient 00026132, study index 011 |
| `00010828_006.png` | Patient 00010828, study index 006 |

## Usage

These files are LFS-tracked. Reference them by their raw LFS media URL, e.g.:

```
https://media.githubusercontent.com/media/microsoft/healthcareai-examples-data/main/medimageinsight/plugin-samples/00026132_011.png
```
